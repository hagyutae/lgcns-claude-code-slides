STEP 0

STEP 0 · LG CNS 사내망 SSL 인증서 설정

  1. SSL240227.zip 다운로드 후 C:\Users\Administrator 에 압축 해제
  2. C:\Users\Administrator\SSL240227\LGCNS_CA_v3.crt 파일 위치 확인
  3. Windows 검색 → 환경 변수 → 시스템 환경 변수 편집
  4. 환경 변수 버튼 클릭 → 시스템 변수에 아래 3개 등록
  5. PowerShell 종료 후 재실행
변수 이름변수 값
NODE_EXTRA_CA_CERTSC:\Users\Administrator\SSL240227\LGCNS_CA_v3.crt
NODE_USE_SYSTEM_CA1
SSL_CERT_FILEC:\Users\Administrator\SSL240227\LGCNS_CA_v3.crt
사내망 SSL 검사 때문에 Claude Code, npm, npx, uv를 실행할 때 인증서 오류가 발생할 수 있습니다.

STEP 4

STEP 4 · PowerShell 실행 정책 설정

  1. Windows 검색 → PowerShell 실행
  2. 아래 명령어 입력 후 A(모두 예) 선택
Set-ExecutionPolicy RemoteSigned
실행 정책을 RemoteSigned 로 바꿔야 합니다.
기본 정책은 서명되지 않은 .ps1 파일을 차단하므로 Claude Code 설치 스크립트와 Python 가상환경의 Activate.ps1 이 실행되지 않습니다.

STEP 5

STEP 5 · uv 설치

  1. PowerShell에서 아래 명령어 입력
irm https://astral.sh/uv/install.ps1 | iex
  1. PowerShell 종료 후 재실행
설치 확인: PowerShell에서 입력
uv --version
uv는 Python까지 직접 설치하고 관리합니다.
Python을 따로 준비하지 않아도 되고, 다른 버전이 이미 설치되어 있어도 문제없습니다.
uv에 필요한 인증서 설정은 STEP 0에서 이미 마쳤습니다.
uv는 Node.js와는 다른 인증서 저장소를 참조하므로 SSL_CERT_FILE 값이 필요합니다.

STEP 7

STEP 7 · PATH 등록추가 조치

STEP 6의 설치 결과에 아래 메시지가 있을 때만 진행합니다.
C:\Users\사용자명\.local\bin is not in your PATH
메시지가 없으면 PATH가 이미 등록된 것이므로 STEP 8로 넘어갑니다.
  1. Windows 검색 → 환경 변수 → 시스템 환경 변수 편집
  2. 환경 변수 버튼 클릭
  3. 사용자 변수 영역에서 Path 선택 → 편집
  4. 새로 만들기 → 설치 시 출력된 경로 입력
  5. 모든 창에서 확인 → PowerShell 종료 후 재실행
C:\Users\사용자명\.local\bin
‘사용자명’은 Windows 계정 이름이므로 사람마다 다릅니다. STEP 6에서 출력된 경로를 그대로 사용하세요.

STEP 8 · API 키 등록

  1. 교육용 API 키 포털 안내 시트 열기 → 빈칸에 본인 이름 입력
  2. 시트에 표시된 ID · PW로 교육용 API 키 포털 접속 → 발급된 키 복사
  3. PowerShell에서 아래 # 3 두 줄 실행
  4. VS Code로 열린 settings.json 에 아래 JSON을 붙여 넣고 ANTHROPIC_API_KEY 값을 본인 키로 바꿔 저장
  5. PowerShell 종료 후 재실행
# 3. 폴더 생성 후 VS Code로 열기
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude" | Out-Null
code "$env:USERPROFILE\.claude\settings.json"
{ "env": { "ANTHROPIC_API_KEY": "sk-ant-api03-XXXXXXXXXXXX" } }
API 키는 개인 자격증명입니다.
화면 공유·캡처·메신저·코드 리포지토리에 노출되지 않도록 주의하세요.

STEP 9 · 실습 리포지토리 준비실습 환경

PowerShell에서 순서대로 실행
# 1. 실습 리포지토리 내려받기
git clone https://github.com/hagyutae/expense-settlement-lab.git C:\Users\Administrator\lab
# 2. 리포지토리 폴더로 이동
cd C:\Users\Administrator\lab
# 3. Python 설치·가상환경 생성·패키지 설치를 한 번에 수행
uv sync
# 4. 가상환경 활성화
.\.venv\Scripts\Activate.ps1
# 5. Claude Code 실행
claude
가상환경을 먼저 활성화한 다음 claude를 실행하세요.
순서가 바뀌면 Claude Code가 가상환경을 인식하지 못합니다. 이 상태에서는 테스트를 실행해도 패키지를 찾지 못해 실패합니다.
uv sync 는 리포지토리에 고정된 Python 버전과 패키지를 그대로 설치합니다.

실행 화면

Claude Code 실행 화면

실습은 Sonnet 5로 진행합니다.
Claude Code를 실행한 뒤 /model 을 입력하고 목록에서 Sonnet 5를 선택하세요. Opus는 응답이 느려 실습을 정해진 시간 안에 마치기 어렵습니다.
  • /model 모델 선택
  • ? 단축키 목록
  • /help 사용 가능한 커맨드 목록
  • /status 인증 상태와 활성 설정
